Analogy एनालॉजी (सादृश्यता)

Interactive version · इंटरैक्टिव नोटPractise this topic · प्रैक्टिस करें

English

Analogy means 'A is to B as C is to ?'. Find how the first pair is related and use the same relation for the second pair. It comes with words, numbers and letters.

📌 Key concepts

Word analogy types

  • Worker and tool: Carpenter : Saw, Tailor : Needle.
  • Product and raw material: Paper : Wood, Butter : Milk.
  • Animal and young one: Cow : Calf, Dog : Puppy, Horse : Foal.
  • Instrument and what it measures: Thermometer : Temperature.
  • Also: country and capital, same meaning, opposite meaning, part and whole.

Number analogy

  • Square or cube: 4 : 16 :: 5 : 25 (n : n²).
  • Square or cube ± 1: 7 : 50 (n² + 1), 3 : 26 (n³ − 1).
  • Multiply by a number, or n × (n + 1): 4 : 20 :: 6 : 42.

Letter analogy

  • Find the shift between the letters of the first pair (ACE : BDF is +1 for each letter).
  • Apply the same shift to the third group.
  • Also check reverse order and opposite letters.

🧮 Formulas and rules

Pair rule
a : b :: c : d → the rule that makes b from a must also make d from c
n : n²
6 : 36 :: 9 : 81
n : n³
3 : 27 :: 4 : 64
n : n² − 1
5 : 24 :: 7 : 48
n : n(n + 1)
4 : 20 :: 6 : 42
Letter shift
ABC : DEF :: GHI : JKL (+3)
Young ones
Cow : Calf, Horse : Foal, Sheep : Lamb, Lion : Cub

✍️ Solved examples

Example 1

Thermometer : Temperature :: Barometer : ?

  1. Make a sentence: a thermometer measures temperature
  2. The same sentence: a barometer measures …
  3. Atmospheric pressure

Answer: Atmospheric pressure

Example 2

7 : 50 :: 9 : ?

  1. 7² + 1 = 49 + 1 = 50, so the rule is n² + 1
  2. 9² + 1 = 81 + 1
  3. = 82

Answer: 82

Example 3

BDF : CEG :: PRT : ?

  1. B → C, D → E, F → G: each letter +1
  2. P → Q, R → S, T → U
  3. Answer = QSU

Answer: QSU

⚡ Quick tricks

  • Make a sentence from the first pair ('a thermometer measures temperature'). The same sentence must fit the answer.
  • For numbers, check n², n³, n² ± 1, n³ ± 1 and simple × first.
  • Test the options: often only one fits the same rule.
  • In letter analogy, write positions and compare the differences.
  • If two options seem to fit, choose the one with the closer, exact relation.

⚠ Common mistakes

  • Reversing the order of the relation (Calf : Cow in place of Cow : Calf).
  • Using a rule that fits the first pair only loosely.
  • Missing a second step in number rules (n² + 1, not just n²).
  • Choosing a related word that does not have the same relation.

हिंदी

एनालॉजी (सादृश्यता) का मतलब 'A का B से जो संबंध है, वही C का ? से'। पहले जोड़े का संबंध खोजें और वही संबंध दूसरे जोड़े पर लगाएँ। यह शब्दों, संख्याओं और अक्षरों में आता है।

📌 ज़रूरी बातें

शब्दों वाली एनालॉजी के प्रकार

  • काम करने वाला और औज़ार: बढ़ई : आरी, दर्ज़ी : सुई।
  • चीज़ और कच्चा माल: काग़ज़ : लकड़ी, मक्खन : दूध।
  • जानवर और उसका बच्चा: गाय : बछड़ा, कुत्ता : पिल्ला, घोड़ा : बछेरा।
  • यंत्र और वह क्या मापता है: थर्मामीटर : तापमान।
  • और भी: देश और राजधानी, एक जैसे मतलब, उल्टे मतलब, हिस्सा और पूरा।

संख्याओं वाली एनालॉजी

  • वर्ग या घन: 4 : 16 :: 5 : 25 (n : n²)।
  • वर्ग या घन ± 1: 7 : 50 (n² + 1), 3 : 26 (n³ − 1)।
  • किसी संख्या से गुणा, या n × (n + 1): 4 : 20 :: 6 : 42।

अक्षरों वाली एनालॉजी

  • पहले जोड़े के अक्षरों में खिसकाव देखें (ACE : BDF में हर अक्षर +1)।
  • वही खिसकाव तीसरे समूह पर लगाएँ।
  • उल्टा क्रम और उल्टे अक्षर भी जाँचें।

🧮 सूत्र और नियम

जोड़े का नियम
a : b :: c : d → जिस नियम से a से b बना, उसी से c से d बनेगा
n : n²
6 : 36 :: 9 : 81
n : n³
3 : 27 :: 4 : 64
n : n² − 1
5 : 24 :: 7 : 48
n : n(n + 1)
4 : 20 :: 6 : 42
अक्षर खिसकाव
ABC : DEF :: GHI : JKL (+3)
जानवरों के बच्चे
गाय : बछड़ा, घोड़ा : बछेरा, भेड़ : मेमना, शेर : शावक

✍️ हल किए गए उदाहरण

उदाहरण 1

थर्मामीटर : तापमान :: बैरोमीटर : ?

  1. एक वाक्य बनाएँ: थर्मामीटर तापमान मापता है
  2. यही वाक्य: बैरोमीटर … मापता है
  3. वायुदाब (हवा का दबाव)

उत्तर: वायुदाब

उदाहरण 2

7 : 50 :: 9 : ?

  1. 7² + 1 = 49 + 1 = 50, तो नियम n² + 1 है
  2. 9² + 1 = 81 + 1
  3. = 82

उत्तर: 82

उदाहरण 3

BDF : CEG :: PRT : ?

  1. B → C, D → E, F → G: हर अक्षर +1
  2. P → Q, R → S, T → U
  3. उत्तर = QSU

उत्तर: QSU

⚡ शॉर्टकट ट्रिक

  • पहले जोड़े से वाक्य बनाएँ ('थर्मामीटर तापमान मापता है')। वही वाक्य उत्तर पर भी फ़िट होना चाहिए।
  • संख्याओं में पहले n², n³, n² ± 1, n³ ± 1 और आसान × जाँचें।
  • विकल्प आज़माएँ: अक्सर एक ही विकल्प उसी नियम पर फ़िट होता है।
  • अक्षरों में स्थान लिखकर अंतर मिलाएँ।
  • दो विकल्प फ़िट लगें, तो जिसका संबंध ज़्यादा सटीक हो वह चुनें।

⚠ आम गलतियाँ

  • संबंध का क्रम उल्टा कर देना (गाय : बछड़ा की जगह बछड़ा : गाय)।
  • ऐसा नियम लगाना जो पहले जोड़े पर ठीक से फ़िट न हो।
  • संख्या वाले नियम में दूसरा कदम छोड़ देना (सिर्फ़ n² नहीं, n² + 1)।
  • ऐसा जुड़ा हुआ शब्द चुनना जिसका संबंध वैसा न हो।
