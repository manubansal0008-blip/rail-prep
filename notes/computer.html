English

Computer questions in RRB are basic: parts of a computer, memory, input-output devices, software, the internet, number systems, full forms and keyboard shortcuts.

📌 Key concepts

Parts of a computer

  • CPU (Central Processing Unit) is the 'brain'; it has the ALU (does arithmetic and logic) and the CU (control unit).
  • Primary memory: RAM is temporary and is lost when power goes off (volatile); ROM is permanent (non-volatile) and holds start-up instructions (BIOS).
  • Cache memory is the fastest memory, between the CPU and RAM. Secondary storage: hard disk, SSD, pen drive, DVD.
  • Input devices: keyboard, mouse, scanner, microphone. Output devices: monitor, printer, speaker. A touch screen is both.

Memory units

1 KB1024 bytes
1 MB1024 KB

Software and the internet

  • System software: operating systems such as Windows, Linux, Android. Application software: MS Word, Excel, browsers.
  • WWW was invented by Tim Berners-Lee (1989). HTTP/HTTPS transfer web pages; DNS turns a website name into an IP address.
  • Email: CC sends a copy that everyone can see; BCC sends a hidden copy.
  • Malware: virus, worm, trojan, ransomware. Phishing is a fake message that tries to steal passwords. A firewall blocks unwanted network traffic.

Number systems, full forms and shortcuts

  • Binary (base 2), octal (8), decimal (10), hexadecimal (16; uses 0–9 and A–F).
  • Full forms: URL – Uniform Resource Locator; HTML – HyperText Markup Language; PDF – Portable Document Format; USB – Universal Serial Bus; LAN – Local Area Network.
  • Shortcuts: Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo, Ctrl+Y redo, Ctrl+S save, Ctrl+P print, Ctrl+A select all, Ctrl+F find.
  • Charles Babbage is called the father of the computer.

✍️ Solved examples

Example 1

Convert binary 1011 to decimal.

  1. Place values from right: 1, 2, 4, 8
  2. 1011 = 1×8 + 0×4 + 1×2 + 1×1
  3. = 8 + 0 + 2 + 1 = 11

Answer: 11

Example 2

How many 2 MB photos can fit in 1 GB of space?

  1. 1 GB = 1024 MB
  2. Number of photos = 1024 ÷ 2
  3. = 512

Answer: 512 photos

Example 3

Convert decimal 25 to binary.

  1. Divide by 2: 25 → 12 r1 → 6 r0 → 3 r0 → 1 r1 → 0 r1
  2. Read the remainders from bottom to top
  3. = 11001

Answer: 11001

⚡ Quick tricks

  • RAM – 'Random, Removed when power off'; ROM – 'Read Only, Remains'.
  • Each memory step is 1024, not 1000.
  • Hex letters: A10 B11 C12 D13 E14 F15.
  • CC = everyone sees; BCC = Blind (hidden) copy.

⚠ Common mistakes

  • Calling ROM volatile; RAM is the volatile one.
  • Taking 1 KB = 1000 bytes in computer questions; use 1024.
  • Reading binary remainders from top to bottom.
  • Calling a monitor an input device.

कंप्यूटर के हिस्से

  • CPU (सेंट्रल प्रोसेसिंग यूनिट) कंप्यूटर का 'दिमाग़' है; इसमें ALU (हिसाब और तर्क करता है) और CU (कंट्रोल यूनिट) होते हैं।
  • प्राथमिक मेमोरी: RAM अस्थायी है और बिजली जाने पर मिट जाती है (वोलाटाइल); ROM स्थायी है (नॉन-वोलाटाइल) और इसमें शुरू होने के निर्देश (BIOS) होते हैं।
  • कैश मेमोरी सबसे तेज़ मेमोरी है, CPU और RAM के बीच। द्वितीयक स्टोरेज: हार्ड डिस्क, SSD, पेन ड्राइव, DVD।
  • इनपुट डिवाइस: कीबोर्ड, माउस, स्कैनर, माइक्रोफ़ोन। आउटपुट डिवाइस: मॉनिटर, प्रिंटर, स्पीकर। टच स्क्रीन दोनों है।

  • WWW का आविष्कार टिम बर्नर्स-ली ने किया (1989)। HTTP/HTTPS वेब पेज भेजते हैं; DNS वेबसाइट के नाम को IP एड्रेस में बदलता है।
  • ईमेल: CC में कॉपी सबको दिखती है; BCC में छिपी कॉपी जाती है।
  • मैलवेयर: वायरस, वर्म, ट्रोजन, रैनसमवेयर। फ़िशिंग नकली मैसेज है जो पासवर्ड चुराने की कोशिश करता है। फ़ायरवॉल अनचाहे नेटवर्क ट्रैफ़िक को रोकता है।

✍️ हल किए गए उदाहरण

उदाहरण 1

बाइनरी 1011 को डेसिमल में बदलिए।

  1. दाईं ओर से स्थानीय मान: 1, 2, 4, 8
  2. 1011 = 1×8 + 0×4 + 1×2 + 1×1
  3. = 8 + 0 + 2 + 1 = 11

उत्तर: 11

उदाहरण 2

1 GB जगह में 2 MB की कितनी फ़ोटो आ सकती हैं?

  1. 1 GB = 1024 MB
  2. फ़ोटो की संख्या = 1024 ÷ 2
  3. = 512

उत्तर: 512 फ़ोटो

उदाहरण 3

डेसिमल 25 को बाइनरी में बदलिए।

  1. 2 से भाग दें: 25 → 12 शेष 1 → 6 शेष 0 → 3 शेष 0 → 1 शेष 1 → 0 शेष 1
  2. शेषफल नीचे से ऊपर पढ़ें
  3. = 11001

उत्तर: 11001

⚡ शॉर्टकट ट्रिक

  • RAM – बिजली गई तो डेटा गया; ROM – डेटा रहता है।
  • मेमोरी का हर कदम 1024 का है, 1000 का नहीं।
  • हेक्स अक्षर: A10 B11 C12 D13 E14 F15।
  • CC = सबको दिखे; BCC = छिपी कॉपी।

⚠ आम गलतियाँ

  • ROM को वोलाटाइल कहना; वोलाटाइल RAM है।
  • कंप्यूटर के प्रश्नों में 1 KB = 1000 बाइट लेना; 1024 लें।
  • बाइनरी के शेषफल ऊपर से नीचे पढ़ना।
  • मॉनिटर को इनपुट डिवाइस कहना।
